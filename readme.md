# Практическая работа 1, вариант 9

## Эмулятор командной оболочки виртуальной файловой системы (VFS)

---

## 1. Общее описание

Проект представляет собой **эмулятор командной оболочки** для виртуальной файловой системы (VFS), реализованный на языке **Python**.

На первом этапе разработки реализован минимальный прототип интерактивного режима работы (REPL — Read-Eval-Print Loop). Эмулятор обеспечивает базовый диалог с пользователем: выводит приглашение к вводу, считывает команды, выполняет их разбор и обрабатывает синтаксические ошибки.

### Поддерживаемые команды (1-й этап)

| Команда | Описание | Статус реализации |
|---------|----------|-------------------|
| `ls`    | Вывод содержимого текущей директории | Заглушка (выводит аргументы) |
| `cd`    | Смена текущей директории | Заглушка (выводит аргументы) |
| `exit`  | Завершение работы эмулятора | Реализовано |

Любая команда, не входящая в список поддерживаемых, вызывает вывод сообщения `Error`.

### Функции модуля `src/main.py`

#### `cli()`

Основная функция эмулятора — реализует интерактивный цикл REPL.

**Поведение:**

1. Выводит приглашение `VFS> `.
2. Считывает строку ввода от пользователя.
3. Разбивает строку на токены по пробелам.
4. Проверяет, что первая команда входит в список разрешённых (`ls`, `cd`, `exit`).
5. При неизвестной команде выводит `Error`.
6. При команде `exit` завершает работу.

**Параметры:** функция не принимает аргументов.

**Возвращаемое значение:** отсутствует (завершает работу по команде `exit`).

### Настройки

На первом этапе настройки задаются непосредственно в коде (`src/main.py`):

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `com_list` | `["ls", "cd", "exit"]` | Список поддерживаемых команд |
| Приглашение ввода | `"VFS> "` | Строка, отображаемая перед вводом |

## 3. Команды для сборки проекта и запуска тестов

### Требования

- **Python 3.8+**
- **pytest** (для запуска тестов)

Установка `pytest`:

```bash
pip install pytest
```

### Запуск эмулятора

**Linux / macOS:**

```bash
chmod +x run.sh
./run.sh
```

**Windows:**

```cmd
run.bat
```

**Альтернативно, напрямую через Python:**

```bash
python3 src/main.py      # Linux / macOS
python src\main.py       # Windows
```

### Запуск тестов

```bash
# Запуск всех тестов
python3 -m pytest tests/ -v

# Запуск тестов с подробным выводом
python3 -m pytest tests/cli_test.py -v

# Запуск конкретного теста по имени
python3 -m pytest tests/cli_test.py -v -k test_cli_commands
```

## 4. Примеры использования

### Пример 1. Интерактивный режим

Запуск эмулятора:

```bash
$ ./run.sh
```

Диалог с пользователем:

```
VFS> ls -la
ls -la
VFS> cd /home/user
cd /home/user
VFS> rm -rf /
Error
VFS> pwd
Error
VFS> exit
```

### Пример 2. Обработка неизвестных команд

Если ввести команду, не входящую в список поддерживаемых, эмулятор выведет `Error` и продолжит работу:

```
VFS> mkdir test
Error
VFS> ls
ls
```

### Пример 3. Завершение работы

Команда `exit` корректно завершает работу эмулятора:

```
VFS> exit
$
```
